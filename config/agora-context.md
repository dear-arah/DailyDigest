Agora (agora.io) is a real-time engagement platform for voice, video, messaging and interactive AI. Its current emphasis is voice agents and conversational AI, with the real-time network (RTC) as the foundation.

## AI products
- Conversational AI Engine (Beta): builds voice agents that work with any LLM, with a choice of speech-to-text (ASR) and text-to-speech (TTS), and with interruption handling. LLM backends include OpenAI, Gemini, DeepSeek, Qwen, Anthropic models, or a custom model.
- Agent Studio: build, deploy and monitor voice agents in the Agora Console without integration code, including phone-call agents through Elastic SIP Trunk, prompts, model selection and call analytics.
- Convo AI Device Kit: voice agents on dedicated hardware such as toys, wearables, kiosks and companion devices ("physical AI").
- Live Avatars: virtual avatars synchronized to speech with low latency.
- Real-Time Speech-to-Text: live captions, transcripts and LLM integration for calls and streams.
- AI Noise Suppression: reduces background noise in real-time audio and video.

## Real-time products
- Video Calling and Voice Calling (RTC)
- Interactive Live Streaming and Broadcast Streaming
- Signaling (RTM): channel messaging, presence and state sync
- Chat, Interactive Whiteboard, Flexible Classroom
- IoT SDK for conversational devices
- Recording, Cloud Transcoding, Media Push and Pull, RTMP Gateway
- Agora Analytics: monitoring, alerts and diagnostics for call quality
- Extensions Marketplace

## Developers and community
- Client SDKs for Android, iOS, macOS, Windows, Web, Electron, Flutter, React Native, Unity and Unreal. Server SDKs for Python, TypeScript and Go.
- Developer tooling: Agora CLI, an MCP server, and a skills pack that teaches AI coding assistants how to build on Agora.
- Community: GitHub organization AgoraIO-Community, blog, events (hackathons, conferences, webinars) and social channels.
- Target use cases: AI tutors and companions, customer-service voice bots replacing IVR, telehealth, live shopping, education, gaming, media and entertainment, voice toys and wearables.

## How to judge a news item
- Competitors in voice agents: LiveKit, Daily and Pipecat, Vapi, Retell, Twilio, Vonage. Competing releases are threats to the Conversational AI Engine, Agent Studio or RTC.
- Voice model vendors (ElevenLabs, Deepgram, Cartesia, AssemblyAI, OpenAI realtime, Google Gemini Live) are potential integrations: new ASR, TTS or realtime models can be offered as options inside the engine.
- LLM provider and model releases matter because the engine supports several LLM backends.
- AI coding assistant and developer-tool news matters for how developers discover and adopt Agora.
- Avatar vendors (HeyGen, Tavus, Anam) are integration candidates for Live Avatars.
- State a threat only when the item names a real overlap with an Agora product. If it is just interesting, tag it fyi.
